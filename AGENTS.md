# MTGallium

Read `AGENTS.local.md` when present for private project preferences.

Work in the current public checkout. Preserve unrelated edits, private research
data, and the Argentum pin. Complete authorized changes through their callers,
tests and documentation; an obsolete API or test is not a reason to preserve a
retired feature.

Ask the owner only about unresolved choices that change the research objective,
game model, or interpretation of retained results. Apply settled decisions.

| Task | Guidance |

| Implement or review code | [Contributing](CONTRIBUTING.md); [architecture](docs/architecture.md) for affected boundaries |
| Change information, actions, simulation or value meaning | [Behavior changes](CONTRIBUTING.md#behavior-changes) |
| Run or resume research | [Python/JVM interface](docs/research-workbench.md); [record organization](docs/research-records.md) |
| Interpret retained results | [Evidence interpretation](.agents/skills/mtgallium-evidence-interpretation/SKILL.md) |

progress report and handoff for the same result. [Record organization](docs/research-records.md)
owns the writing rules.
